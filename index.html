what this makes
a real shell link binary file. the header carries the class id 00021401-0000-0000-c000-000000000046, optionally followed by a link-target id list (the pidl trail), then a link-info block holding a volume id and both ansi and unicode copies of the base path, then the unicode string data section (name, relative path, working dir, arguments, icon), and a terminal block. embedded times are left unset. no server touches the file — it is assembled in your browser and handed straight to a download, and the decoder above reads one back the same way.
